# 侯瑞超个人学术主页

本项目完全参照 `DZSYUNNAN/aca` 的 Next.js + Tailwind 学术主页模板制作，并替换为侯瑞超老师的个人信息。

## 本地运行

```powershell
npm install
npm run dev
```

打开 <http://localhost:3000>。

## 构建

```powershell
npm run build
```

## GitHub Pages

推送到 `main` 分支后，仓库内置的 `.github/workflows/deploy.yml` 会自动构建并部署到 GitHub Pages。

头像文件位于 `public/profile-photo.jpg`。
